How the Excel file is used

  • Entering results: Export the current students file, add a new column with scores, import it back as a dry run, then commit.
  • Admitting new students: Add rows to the bottom of the file with new admission numbers (DSA500+), import — they'll be created with default PIN 1234.
  • Clearing a student: Set is_active=no and import. They can no longer sign in but their records stay.
  • Updating fees: Set fees_balance and fees_cleared=yes/no, then import.
  • Parent registration: Parents who sign up on the web are matched against the admission_number + student_name in the file before their account goes live.
